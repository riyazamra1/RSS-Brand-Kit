# RSS Global UI Rules

1. Modern, professional, lightweight Android UI.
2. Original RSS logo unchanged.
3. Project logo remains project-specific.
4. Use consistent spacing, typography, corner radius and elevation.
5. Cards generally use an icon on the left and content on the right.
6. Use meaningful colorful icons where appropriate.
7. Avoid obsolete-looking UI.
8. Avoid excessive animation.
9. Respect accessibility and readable contrast.
10. Light and dark themes must update the complete application.
11. Never oversize logos.
12. Responsive layouts must work across Android screen sizes.

Priority: project-specific explicit instructions override these rules for that project.
