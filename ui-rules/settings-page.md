# RSS Settings Page

Default structure:
- App/project identity at the top where appropriate, using the project's own original app logo.
- Grouped settings sections.
- Colorful, meaningful icon on the left.
- Setting title/content on the right.
- Clear section hierarchy.
- Modern cards and separators.
- Light/dark/system theme support.
- Animated section entrance, navigation, selection, and state changes.
- RSS company-branding section near the bottom where appropriate.

Common company section may include the unchanged original RSS logo, Razeen Secure Solution, About, Contact, Terms, Privacy and version information.

Do not force irrelevant common settings into a project.
