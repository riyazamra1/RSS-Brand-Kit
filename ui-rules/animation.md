# RSS KIT Animation System

Animation is a **global RSS KIT default**.

## Required animated areas
- Registration / Create Account
- Login where present
- Welcome experience
- Feature introduction pages
- Main/home content
- Slide-menu opening, closing, and selection states
- Settings
- About
- Contact
- Privacy Policy
- Terms & Conditions
- Loading, success, error, and meaningful state changes where appropriate

## Motion principles
- Smooth and purposeful.
- Lightweight and responsive.
- Prefer short fade, slide, scale, and content-stagger transitions.
- Animate hierarchy and state changes, not every element continuously.
- Avoid motion that interferes with reading or task completion.
- Respect platform accessibility/reduced-motion behavior where available.
- Theme changes should transition cleanly without breaking the UI.

## Project overrides
A project-specific animation requirement may replace this default for that project. Otherwise, RSS KIT animation is expected throughout the experience.
