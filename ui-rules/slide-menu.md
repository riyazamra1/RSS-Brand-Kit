# RSS Slide Menu

The RSS slide menu is a **mandatory standard navigation pattern** unless a project explicitly requires a different information architecture.

## Structure
- Correctly sized **project/app logo** in the app identity area.
- Welcome text where appropriate.
- User name.
- User email.
- Separator.
- Major navigation destinations with meaningful colorful icons.
- Clear selected/current state.
- Separator.
- Bottom RSS company-branding section with the original RSS company logo unchanged.
- Company name and appropriate RSS/company details.
- App version where appropriate.

## Glassmorphism standard
- The drawer surface must have a modern glassmorphism appearance.
- Use a translucent/surface-tinted layer, subtle border, depth/elevation, rounded corners, and theme-aware contrast.
- Where platform/library support permits, use lightweight blur; otherwise preserve the glass appearance through translucency, layering, border, and tonal depth.
- Never allow the glass effect to reduce text/icon readability.
- Light and dark themes must each have an intentional glass treatment.
- Drawer opening/closing and menu-item state changes should be smoothly animated.

## Interaction
- Touch-friendly rows with generous hit areas.
- Smooth selection feedback.
- Predictable left-to-right Android drawer behavior by default.
- Do not use an outdated stock-looking drawer presentation.

Project-specific navigation requirements override this document.
