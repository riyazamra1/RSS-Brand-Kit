# RSS Slide Menu

Default navigation drawer direction: left-to-right standard Android drawer unless the project explicitly requires another pattern.

Header:
- Correctly sized RSS/project logo
- Welcome text where appropriate
- User name
- User email

Visual:
- Modern glassmorphism-inspired treatment where appropriate
- Clean spacing
- Rounded surfaces
- Meaningful colorful icons
- Clear selected state
- Premium but lightweight appearance

The menu must not look like an outdated default Android drawer.

Project-specific navigation requirements override this document.
