# RSS Brand Rules

## Identity

Company: Razeen Secure Solution
Short brand: RSS

## Logo

Use the original RSS logo unchanged.
- No recoloring
- No stretching
- No distortion
- No redesign
- No replacement logo
- No excessive sizing
- Preserve transparent background when supplied

## Visual direction

Default: modern, premium, professional, lightweight Android UI.

Preferred brand direction: black + gold, adapted for accessibility and the active theme.

## Project logos

A project may have its own original project logo. Use that logo for project identity while retaining RSS company branding in common/company areas.

## Priority

Project-specific explicit branding instructions may override these defaults for that project.
